# 🚀 Professional Web Portfolio - Kevin Garcia

Welcome to my personal web portfolio! This project is a Single Page Application (SPA) natively built with JavaScript. It is designed to showcase my experience, technical skills, key projects, and contact channels in an interactive, responsive, and optimized way.

---

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling:** Tailwind CSS, FontAwesome
- **UI Libraries / Components:** `@tailwindplus/elements`
- **Build Tool (Bundler):** Vite
- **Deployment:** Vercel

---

## ⚙️ Key Features

- **SPA Navigation (Single Page Application):** Dynamic routing system built in vanilla JavaScript without page reloads.
- **100% Responsive Design:** Optimized for mobile devices, tablets, and desktop screens.
- **Modular Components:** Clean structure based on reusable UI components (`Navbar`, `Footer`, modular views).
- **Animations & Interactivity:** Mobile dropdown menu and dynamic counter animations using `IntersectionObserver`.

---

## 📂 Project Structure

```text
├── public/              # Static assets (images, favicons, PDF resume)
├── src/
│   ├── components/      # Reusable UI components (Navbar, Footer)
│   ├── router/          # Client-side routing configuration and views mapping
│   ├── views/           # Main page views (About, CV, Portfolio, Skills, Contact)
│   ├── main.js          # Main entry point and router initialization logic
│   └── style.css        # Global styles
├── index.html           # HTML template entry
├── package.json         # Project metadata, dependencies, and scripts
└── vite.config.js       # Vite bundler configuration
```

---

## 💻 Local Installation and Setup

To clone and run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/keyvler04/cv.git](https://github.com/keyvler04/cv.git)
   cd cv
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173`.

4. **Build for production:**
   ```bash
   npm run build
   ```

# 🚀 Portafolio Web Profesional - Kevin Garcia

¡Bienvenido/a a mi portafolio web personal! Este proyecto es una Single Page Application (SPA) desarrollada de forma nativa con JavaScript, diseñada para mostrar mi experiencia, habilidades técnicas, proyectos relevantes y canales de contacto de forma interactiva y optimizada.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Estilos:** Tailwind CSS, FontAwesome
- **Librerías / Componentes UI:** `@tailwindplus/elements`
- **Herramienta de Construcción (Bundler):** Vite
- **Despliegue:** Vercel

---

## ⚙️ Características Principales

- **Navegación SPA (Single Page Application):** Sistema de enrutamiento dinámico en JavaScript sin recargar la página.
- **Diseño 100% Responsivo:** Adaptado para dispositivos móviles, tablets y pantallas de escritorio.
- **Componentes Modulares:** Estructura limpia basada en componentes reutilizables (`Navbar`, `Footer`, vistas modulares).
- **Animaciones e Interactividad:** Menú desplegable móvil optimizado y contadores numéricos dinámicos mediante `IntersectionObserver`.
